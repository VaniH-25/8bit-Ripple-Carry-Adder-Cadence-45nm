# 8-bit Ripple Carry Adder using Cadence Virtuoso (45nm)

## Project Overview

This project presents the transistor-level design and simulation of an **8-bit Ripple Carry Adder (RCA)** using **Cadence Virtuoso** in **45nm CMOS technology**.
